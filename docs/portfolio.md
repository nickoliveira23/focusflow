# Portfolio Notes

## Why BMAD is in this repo

The project includes BMAD artifacts on purpose to demonstrate:

- product thinking (`prd.md`)
- architecture decisions (`architecture.md`)
- delivery planning (`epics.md`)
- implementation tracking (`sprint-status.yaml`)

This is not just code output. It is a full product-engineering lifecycle snapshot.

## What this project demonstrates

- monorepo organization
- frontend architecture with reusable components/hooks
- backend modularization with routes/controllers/services/repositories
- auth integration (Google OAuth, mock support)
- local-first behavior + sync patterns
- automated tests and quality gate scripts

## Scope choices

- Spotify integration is intentionally constrained until Premium access is available.
- Focus was on a stable MVP with room for incremental feature hardening.
